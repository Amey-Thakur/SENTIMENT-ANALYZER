<a name="overview"></a>
## Overview

**SENTIMENT-ANALYZER** is a specialized Natural Language Processing (NLP) framework designed to quantify affective states within textual datasets. By translating human linguistics into empirical sentiment scores, this repository provides a foundational bridge between raw text and actionable psychological insights.

*   **Linguistic Affect Analysis**: Utilizes the TextBlob pipeline to perform real-time polarity and subjectivity assessments.
*   **Neural Semantic Inference**: Includes a deep learning topology (Keras/TensorFlow) designed for the IMDB dataset, demonstrating the transition from rule-based to probabilistic sentiment detection.
*   **Scholarly Architecture**: Prioritizes code readability and formal documentation, making it an ideal resource for academic study and research.

<a name="quick-start"></a>
## Quick Start

### 1. Prerequisites
- **Python 3.9+**: Recommended for optimal runtime compatibility.
- **Git**: For version control.

### 2. Installation & Setup

#### Step 1: Clone the Repository
```bash
git clone https://github.com/Amey-Thakur/SENTIMENT-ANALYZER.git
cd SENTIMENT-ANALYZER
```

#### Step 2: Configure Environment & Dependencies
```bash
pip install -r "Source Code/requirements.txt"
```

### 3. Execution
Launch the primary sentiment analysis engine:

```bash
python "Source Code/app.py"
```
